# Financial Planner

A little web app I built that helps figure out where money should actually go. You type in your salary, your fixed expenses like rent and car loan, and which country you're in — then it talks to an AI and spits out a full budget breakdown with a chart, tips, and an honest score on how healthy your finances look.
